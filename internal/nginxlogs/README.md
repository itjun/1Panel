# Nginx 日志压缩下载

入口为远程主机 Nginx 配置页面的“下载日志”。默认只导出 `/var/log/nginx` 中当天的日志记录，允许指定其他日志目录；不会从当前选中的 `.conf` 自动推断站点日志。临时目录默认 `/var/tmp`，可改为另一块磁盘的目录。

## 当日范围

- 按远程主机日期固定当天的零点至次日零点，跨午夜运行不会自动切换日期。日志自带时区时先换算到该范围；没有时区的 Nginx 错误日志按主机时区处理。
- 根据每行时间筛选，不能仅依据文件名或修改时间判断。支持标准 Nginx 访问日志的 `[15/Oct/2026:12:00:00 +0800]`、错误日志的行首 `2026/10/15 12:00:00`，以及行首 ISO 8601 或 JSON `time`、`time_iso8601`、`timestamp`、`@timestamp` 字段中的 ISO 8601 时间。
- 扫描当前普通文本日志和未压缩轮转日志，跳过 `.gz` 等历史压缩包。没有当日记录的文件不进入压缩包；无法识别时间的行（包括无时间戳的续行）不导出，并在界面显示数量。没有任何当日记录就提示，不回退为全量导出。
- 筛选和压缩均限速；只在内存保留命中行的字节范围，不落盘未压缩副本。单行最多 1 MiB、总共最多 10000 个不连续片段，超限即停止；空间预算按筛选后的内容估算。

## 执行边界

- 目标为 Linux SSH 主机，需要 Python 3、nice、ionice、GNU stat，以及当前 SSH 用户对日志的读权限和临时目录的写权限。缺少能力就报错，不安装依赖、不自动 sudo，也不改变 Nginx 配置。
- 用独立 SSH 会话运行一次性进程，无须升级 spanel-agent。nice 19 + ionice idle 必须设置成功，使用单进程 gzip level 1；分块 256 KiB，读／传输上限 2 MiB/s，并按进程 CPU 时间控制到平均约单核 20%。这是一套尽量降低影响的措施，不能保证任意硬件／调度器下业务延迟绝对不变。
- 压缩前按日志逻辑大小、tar/PAX 开销和不可压缩数据的膨胀估算上限。临时目录所在文件系统必须再保留 `max(1 GiB, 总容量的 10%)`，拒绝 tmpfs/ramfs；压缩和下载持续检查可用空间；同时检查日志所在文件系统的预留空间，每个文件压缩完即释放只读描述符，避免延迟轮转文件的空间回收。本机预留 512 MiB，同样先检查预算、写入时再次检查。
- 每个文件打开只读描述符并固定初始长度。后续追加不包含在导出中，rename 轮转后仍读取原 inode；发现截断就失败。它不是文件系统原子快照：外部 copytruncate 后立即重新增长或原地改写无法提供严格一致性保证。
- 不调用 nginx、logrotate、kill nginx、reload、restart；不截断、删除或重命名原始日志。跳过符号链接、FIFO、设备；最多 512 个普通文件、10000 个目录条目，防止无限遍历与描述符耗尽。
- 同一主机的同一远程 UID（锁位于固定 `/tmp`，切换临时目录也无法绕过） 用 flock 排斥并行任务。完整压缩包生成后才传输，SSH stdout 只承载二进制，stderr 承载结构化进度。
- 任务最长 12 小时；取消仅关闭本次会话。stdin 心跳中断／EOF（最长 15 秒）触发工作进程清理；正常结束、错误及可捕获信号均清理自建临时目录。主机掉电或 SIGKILL 后无法保证自动清理。
- 本地先写同目录私有 `.part` 文件，大小与 SHA-256 校验通过、远程成功退出后再替换用户选定的文件。失败／取消不覆盖旧文件，删除未完成的本地临时文件。

## 验证

```sh
go test -race ./internal/nginxlogs
python3 -B -m unittest discover -s internal/nginxlogs -p '*_test.py' -v
```

Go 测试使用真实 SSH 协议的本地测试服务，覆盖当日筛选后的实际下载、校验失败、远程失败、保留已有文件、取消以及共享连接仍可使用。Python 测试覆盖主机时区、跨日／夏令时边界、混合日期、历史包排除、未知时间、内存限制、读写并行语义、轮转、截断、特殊文件、空间不足、并发锁、限速和心跳中断清理。

macOS 测试中 Linux 环境检查在子进程清理用例中被替换；Linux 的实际 ionice／文件系统检查需要在 Linux 测试机验收。测试不会连接用户保存的主机，不会操作线上 Nginx。
