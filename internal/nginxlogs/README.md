# Nginx 日志压缩下载

入口为远程主机 Nginx 配置页面的“下载日志”。默认只导出 `/var/log/nginx` 目录下的 `access.log` 和 `error.log`，原样打进同一个压缩包，使用 `zstd -q -c` 生成 `.tar.zst`；tar 经管道直接压缩，压缩级别、线程和帧校验采用 zstd 默认值。允许指定其他日志目录；不会从当前选中的 `.conf` 自动推断站点日志。临时目录默认 `/var/tmp`，可改为另一块磁盘的目录。

点击入口立即显示对话框遮罩；点击“压缩并下载”时先同步锁定请求并绘制忙碌蒙层，再打开保存窗口。等待保存位置、连接、压缩和下载期间均拦截重复点击及回车，阻止通过 Esc 或外部点击关闭，只允许取消当前任务。成功保存后自动关闭弹窗和蒙层，在页面提示保存路径；失败或取消保留弹窗，释放锁后允许重试。

## 文件范围

- 只按固定名称打开所选目录中的 `access.log`、`error.log`，不枚举目录、不访问子目录，不读取轮转日志、历史压缩包、改名备份或其他文件。
- 不筛选日期，不预读日志内容；旧日期、无时间戳内容、多行错误和空文件原样保留。缺失或不是普通文件的目标会跳过并显示数量；两者都不可用则报错，权限不足等读取错误不会静默跳过。
- 空间预算直接按两个文件的初始大小保守估算，预检后直接压缩。界面显示“日志原始大小”和压缩／下载进度，不再显示扫描量或当日大小。
- 只读取每个文件打开时固定的长度，压缩期间新增的内容留待下次下载。

## 执行边界

- 目标为 Linux SSH 主机，需要 Python 3.7+、zstd、GNU stat，以及当前 SSH 用户对日志的读权限和临时目录的写权限。缺少能力就报错，不安装依赖、不自动 sudo、不静默切换压缩格式，也不改变 Nginx 配置。
- 用独立 SSH 会话运行一次性进程，无须升级 spanel-agent。按用户要求直接使用 zstd 默认参数，不设置压缩级别、线程数、nice／ionice 优先级、吞吐限速或 CPU／内存预算；保留 256 KiB 分块流式读写及磁盘检查。
- 压缩管道采用非阻塞写入，即使子进程不再消费输入，也能检查磁盘空间并响应取消。
- 压缩前按日志逻辑大小、tar/PAX 开销和不可压缩数据的膨胀估算上限。临时目录所在文件系统必须再保留 `max(1 GiB, 总容量的 10%)`，拒绝 tmpfs/ramfs；压缩和下载持续检查可用空间；同时检查日志所在文件系统的预留空间，每个文件压缩完即释放只读描述符，避免延迟轮转文件的空间回收。本机预留 512 MiB，同样先检查预算、写入时再次检查。
- 每个文件打开只读描述符并固定初始长度。后续追加不包含在导出中，rename 轮转后仍读取原 inode；发现截断就失败。它不是文件系统原子快照：外部 copytruncate 后立即重新增长或原地改写无法提供严格一致性保证。
- 不调用 nginx、logrotate、kill nginx、reload、restart；不截断、删除或重命名原始日志。跳过符号链接、FIFO、设备；最多打开两个日志文件，不遍历目录。
- 同一主机的同一远程 UID（锁位于固定 `/tmp`，切换临时目录也无法绕过） 用 flock 排斥并行任务。完整压缩包生成后才传输，SSH stdout 只承载二进制，stderr 承载结构化进度。
- 任务最长 12 小时；取消仅关闭本次会话。stdin 心跳中断／EOF（最长 15 秒）触发工作进程清理；先关闭管道，终止并回收 zstd（终止后 2 秒不退出则强制结束该子进程），再删除自建临时目录。下载成功、取消、断线、压缩失败均清理远程临时包，没有额外保留期；本机成功下载的文件保留。主机掉电或 SIGKILL 后无法保证自动清理。
- 本地先写同目录私有 `.part` 文件，大小与 SHA-256 校验通过、远程成功退出后再替换用户选定的文件。失败／取消不覆盖旧文件，删除未完成的本地临时文件。

## 验证

```sh
go test -race ./internal/nginxlogs
python3 -B -m unittest discover -s internal/nginxlogs -p '*_test.py' -v
# 可选：隔离临时目录内 1 GiB 输入
NGINX_LOGS_LARGE_TEST=1 python3 -B -m unittest discover -s internal/nginxlogs -p '*_test.py' -k gib -v
```

本机测试需要 Python 3 和 zstd。Go 测试使用真实 SSH 协议的本地测试服务，覆盖两个原始日志的实际下载、校验失败、远程失败、保留已有文件、取消以及共享连接仍可使用。Python 测试覆盖固定文件范围、预检不读取日志内容、混合日期与无时间戳内容原样保留、空文件、缺失文件、历史包排除、读写并行语义、轮转、截断、特殊文件、空间不足、不可压缩内容与帧校验、压缩子进程异常、并发锁和心跳中断清理。

macOS 测试中 Linux 文件系统检查被替换；实际 Linux 环境检查需要在 Linux 测试机验收。测试不会连接用户保存的主机，不会操作线上 Nginx。
