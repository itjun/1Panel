主机状态，
一眼看清。

CPU、内存、磁盘、进程与服务，集中在一个桌面面板。沿用本机 SSH 配置，连接远程主机，也能查看当前电脑。

macOS · Windows · Linux MIT 开源

从看状态，到处理事情。

远程主机与本机工作区，在同一个应用里。

主机集中查看

按项目分组，查看 CPU、内存、磁盘和负载。进入主机后，继续查看进程、Java、Docker、服务和定时任务。

沿用你的 SSH 配置

读取本机的 SSH 配置，使用已有密钥、端口和跳板机设置。已配置的主机自动加载，也能在应用中添加。

本机也有工作区

查看当前电脑的系统概览、应用进程、磁盘和网络信息，日常排查不必来回切换工具。

终端随时接上

通过内嵌终端或系统已安装的终端继续操作。macOS 也可配合 1Agent 打开对应主机会话。

主机资源，持续关注

查看资源趋势与主机状态，在面板中发现需要关注的主机，再进入详情定位问题。

公开源码，自由使用

项目以 MIT 协议开源。安装使用 GitHub Releases 提供的完整安装包，也可以阅读源码、提交问题与建议。

第一次在 Mac 上打开？

当前免费分发版本尚未经过 Apple 公证。可在“系统设置 → 隐私与安全性”中手动确认，也可按指南使用终端命令处理。
