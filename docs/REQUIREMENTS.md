# 1Panel — 原始需求与功能说明文档

> 一个 macOS 原生的运维管理面板，读取本机 `~/.ssh/config`，分组管理 SSH 主机，提供实时监控、文件浏览、终端等一站式运维能力。

---

## 一、背景与目标

运维人员日常需要同时管理多台 Linux 服务器，现有工具（如 Xshell、Termius）要么功能割裂（监控和终端分开），要么依赖外部账号体系（数据不落地）。

1Panel 的目标：**在本机直接读取已有的 SSH 配置，零额外配置成本，提供「监控 + 文件 + 终端」一体化面板**。所有连接复用用户自己的 SSH 密钥，不经过任何第三方服务。

## 三、功能模块详解

### 3.1 主机列表与分组

#### 主机列表
- 自动解析 `~/.ssh/config`，展示所有 Host 条目
- 默认过滤 Git 托管服务（github.com / gitee.com / gitlab.com 等），可切换显示
- 左侧侧边栏按分组树形展示，支持搜索（按主机名或 IP 过滤）
- 显示信息：主机别名、user@IP、非默认端口的端口徽标

#### 分组管理
- 创建/重命名/删除分组（本地存储，不修改服务器）
- 把主机分配到分组：**拖拽** 或右键菜单
- 每个分组显示主机数量
- 未分配的主机自动归入「未分组」

#### 分组概览页
- 点击分组名进入概览页，卡片网格展示该组所有主机
- 每张卡片：发行版 logo、CPU/MEM/DISK/LOAD 四行进度条、红/黄/绿状态灯
- 顶部摘要条：总台数 / 正常数 / 告警数 / 连接失败数
- 并发采集（上限 5），单台失败不影响其它
- 卡片点击进入主机详情

### 3.2 主机详情

进入单台主机后，顶部显示主机别名 + user@IP:port，下方 8 个功能 Tab：

#### ① 概览（Overview）
| 指标 | 说明 |
|---|---|
| 操作系统 | 发行版名称（如 Ubuntu 24.04.3 LTS） |
| 内核版本 | uname -r |
| CPU 型号 + 核数 | model name + processor 计数 |
| 运行时长 | 启动至今的天数 |
| CPU 使用率 | 两次采样差分计算（非累计平均），2 秒刷新 |
| 内存使用率 | 已用/总量 + 百分比 + 趋势曲线 |
| 系统负载 | 1/5/15 分钟负载，按核数判定轻松/正常/紧张 |
| Swap | 使用率 + 已用/总量，未启用时提示 |
| 磁盘 | 各分区使用率（过滤 docker/snap/容器挂载），足够大的盘/分区可用 ≤ 10 GB 红色 |

#### ② 进程（Processes）
- 按 CPU 使用率排序的进程列表（PID/PPID/用户/CPU%/MEM%/RSS/运行时长/命令行）
- 支持按列点击排序、按命令/用户/PID 过滤搜索
- 切换「全部进程」/「仅 Java 进程」（按 comm=="java" 精确过滤）
- 每个进程可操作菜单：结束进程（SIGTERM）/ 强制结束（SIGKILL）

#### ③ Docker
- 容器卡片列表（名称/镜像/状态/端口）
- 实时资源占用（CPU%/内存用量·上限/网络 IO/块 IO）
- 操作菜单：启动 / 停止 / 重启（action 白名单校验）
- 目标机无 Docker 时显示空态

#### ④ 文件（Files）
- **左侧目录树**：懒加载子目录，可展开/折叠，点击切换列表路径
- **中间文件列表**：名称/大小/所有者/修改时间，目录在前
- **面包屑导航**：根 > etc > nginx，点击跳转，支持后退
- **文件预览面板**：点击文件查看内容（限制 512KB，防止拉巨型文件）
- **拖拽上传**：从 Finder 拖文件到文件区，SFTP 上传到当前目录
- **只读原则**：文件浏览只支持查看和上传，不支持远程删除/重命名/编辑

#### ⑤ 服务（Services）
- systemd 运行中的服务列表（名称/Load/Active/Sub）
- 只读查看，不做启停操作

#### ⑥ 定时任务（Cron）
- 合并展示三类来源：用户 crontab / `/etc/crontab` / `/etc/cron.d/*`
- 自动过滤环境变量定义行（SHELL=/bin/sh 等）
- 标注每条的来源类型

#### ⑦ 软件包（Packages）
- apt 已安装包列表（名称/版本/**依赖数**）
- 依赖数：解析 Depends 字段统计（处理 | 选择项、版本约束、架构后缀）
- 搜索框（按包名/版本过滤）、点击列头排序
- 统计摘要：总包数 / 平均依赖数 / 最多依赖数
- 大列表分页（默认显示前 500 条，引导用搜索缩小范围）

#### ⑧ 终端（Terminal）
- 内嵌 xterm.js，支持 256 色、光标闪烁、Web 链接点击
- 可新开多个终端会话（Tab 条切换，独立 ssh 连接）
- 输入回显正常（PTY 模式），支持 Tab 补全、方向键、Ctrl+C、全屏程序（vim/top）
- 窗口大小变化时自动同步 PTY 尺寸
- 快速输入不卡顿（输入批量合并 + 输出碎片合并）
- 关闭 Tab 自动断开 SSH 连接，退出时显示「连接已关闭」

### 3.3 多标签页

- 主区域顶部标签条，可同时打开多台主机或分组
- **单击**侧边栏主机/分组 → 打开或聚焦已有标签页
- **右键**侧边栏 → 菜单：在新标签页打开 / 跳转到此主机 / 复制 user@ip / 重命名
- **右键**标签条上的标签 → 菜单：关闭 / 关闭其它
- 标签 × 按钮关闭，活跃自动切到相邻标签
- 每个标签记住自己的子 Tab 位置（A 主机看进程 → 切到 B → 切回 A 还在进程页）
- 已打开的主机在侧边栏显示蓝色小圆点指示器

### 3.4 主机管理操作

#### 添加主机
- 输入 IP/用户/端口/密码 → 自动 ssh-copy-id 安装公钥 → 回写 `~/.ssh/config`
- 回写前自动备份 ssh config（`.bak.时间戳`）
- 密码仅本次使用，不落盘

#### 重命名主机别名
- 右键主机 → 「重命名」→ 输入新别名
- 自动更新 `~/.ssh/config` 里的 Host 行（写前备份）
- 自动同步 `groups.json` 里的分组引用
- 自动关闭旧 SSH 连接（下次用新别名重建）
- 校验：新别名非空、无空格/通配符、不重名

### 3.5 设置面板（⌘+,）

| 设置项 | 说明 |
|---|---|
| 主题 | 6 选 1：暗黑 / 明亮 / 墨蓝 / 墨绿 / 樱花 / 跟随系统 |
| 字体类型 | 系统默认 / SF Mono / JetBrains Mono / Fira Code / 苹方 / 思源黑体 等 |
| 字体大小 | 10~18px 滑块 |
| 页面缩放 | 80%~140% 滑块（含图表） |

- 顶部工具栏调色板图标可快速循环切换主题（⌘+⇧+T）
- 设置持久化到 localStorage，下次启动自动恢复

## 四、预警阈值

| 指标 | 阈值 | 颜色 |
|---|---|---|
| CPU 使用率 | ≥ 90% | 红色 |
| 内存使用率 | > 85% | 红色 |
| 磁盘可用空间 | 任一足够大的盘/分区可用 ≤ 10 GB | 红色 |
| 负载比（load1 / 核数） | > 2.0 | 红色 |
| 连接失败 | — | 红色边框 + 红灯 |
| 有任一指标超阈值 | — | 黄色边框 + 黄灯 |
| 全部正常 | — | 绿灯 |

## 五、错误处理策略

- **静默失败**：单台主机采集出错不影响其它主机，错误记录到快照的 Error 字段
- **断线节流**：连接失败后 30 秒内不重试，避免雪崩
- **连接复用**：一个主机维护一个 SSH 长连接，所有采集复用，连接断开自动重建
- **命令超时**：单条采集命令 30 秒超时，防止卡死

## 六、安全说明

- 应用**不打包任何 SSH 密钥或证书**——纯二进制
- 运行时只读取用户本机的 `~/.ssh/config`（只读解析），不上传不泄露
- SSH 连接使用用户自己的密钥认证，密码仅在「添加主机」时临时使用
- Host key 校验使用 `InsecureIgnoreHostKey`（内部工具，不做指纹校验）
- 监控采集全部为**只读命令**，写操作仅限：结束进程 / Docker 启停 / 文件上传（用户主动触发）
- 分组数据存储在本机 `~/Library/Application Support/ServerPanel/groups.json`

---

## 七、平台与限制

- **运行平台**：macOS 12+（当前仅打 Apple Silicon arm64 单架构）
- **目标主机**：Debian/Ubuntu 系列（依赖 systemd / apt / /proc）
- 其它发行版部分监控字段（systemctl / dpkg-query）可能不可用
- 终端复用用户本机 PATH 中的 `ssh` 二进制配置

## 八、分发说明

1. 解压 `ServerPanel-v1.0-arm64-mac.zip` 得到 `.app`
2. 拖入 `/Applications`
3. 右键 → 打开（macOS Gatekeeper 拦截未签名应用，仅需一次）
4. 确保本机已配置 `~/.ssh/config` + 密钥 + `ssh-copy-id`
