# 1Panel UI/UX 落地验收记录（2026-10-18）

以批准的原型布局调整正式 React/Wails 实现。保留现有路由、主机/机柜身份、持久化键、Panel JSON 来源规则和 SSH/Agent 协议。新增内容均为界面状态；没有新增任务中心或业务备份/恢复能力。

## 已落地范围

| 阶段 | 实施结果 |
| --- | --- |
| 通栏与导航 | 本机与远程工具共用通栏；测量真实标签宽度，活动工具始终可见；≤1050px 使用主机/分区浮层，手动侧栏宽度和展开偏好独立保留；最小窗口 900×700。 |
| 分组与工作台 | 保留机柜/分组/主机拖拽、选择与菜单；指标、趋势、诊断优先，完整硬件明细保留；本机摘要与远程指标层级对齐。 |
| 设备工具 | 正式页面共用标题、操作行、表格和响应式规则；保留现有图表、筛选、排序和跨模块入口；文件默认远程单栏，按需展开现有本机传输对端。 |
| 配置中心 | 保留五分区和真实引擎；SSH 草稿不再因分区切换丢失，空 JSON 草稿也受保护；SSH 根配置定位准确；快照详情防止过期请求回写，时间线保持选中项可见。 |
| 全局模块 | 通知列表/详情、测速参数/历史、巡检和设置使用统一分区布局；保留订阅、未读定位、测速曲线、巡检操作和全部设置；清理重复标题与创建入口。 |
| 集成安装 | macOS 应用已打包、签名、替换安装并启动；真实主机/分组、配置五分区、快照、文件双栏、本机通栏和测速历史已做只读复查。原生 900×700 复测等待手动缩窗。 |

主机切换沿用正式项目的全局当前工具规则，不引入原型的模拟状态。文件路径、历史、冲突处理、删除确认和上传下载继续使用现有实现；不新增远程间传输。

## 验证证据

- 正式项目 `bun run type-check`、`bun run build`、`bun run verify:shell` 均通过。
- 15 个前端测试文件分别运行，131 项测试通过。另运行机柜布局、分组表格、SFTP 路径、工作区迁移和看板等既有脚本。
- `go test ./...` 通过，新增最小尺寸/旧窗口记录兼容测试通过。配置迁移、冲突密钥、恢复和路径边界测试使用现有临时目录测试。
- 正式组件隔离验收使用仓库组件和独立 API 测试夹具，不连接真实主机、不写实际配置。覆盖 900/1050/1198/1688px，1/2/3/4/5/8/16 台分组；检验浮层与更多互斥、多选与 Shift 连选、键盘切换、活动工具可见、浅/深色、20px 字号和 400px 侧栏。
- 隔离验收确认 SSH 草稿切换后保留，快照快速切换后详情仍对应选中项。原生验收只读取真实配置与历史，没有执行真实恢复、文件删除、上传或配置提交。
- 额外执行的既有 `test-pointer-action.mjs` 失败：脚本未模拟当前 helper 依赖的 document 捕获 click 事件；脚本与 helper 均与开始时基线完全一致。本轮未修改此旧脚本，真实界面的指针、多选与键盘切换已验证。
- 主题测试存在同进程 mock 污染，按测试文件隔离运行后均通过。构建仍有既有大 JS 分包提示；未为本次视觉调整扩展构建重构。

## 配置、数据与提交边界

安装前备份旧应用包，并为原数据目录及 SSH 配置建立文件校验清单。启动复查确认原主机 31 台、分组 12 个可见，原数据文件均仍存在，Panel JSON、SSH 配置、既有快照和历史校验一致。会话和窗口记录会随正常退出/启动及界面操作更新。

开始时的三个未提交文件已保存基线；它们保持字节一致且未暂存。本轮提交仅包含本轮改动，不推送。应用包包含当前工作区中原有、未修改的基线内容。

## 回退与剩余验收

回退时正常退出 1Panel，将同次验收归档 `production-rollout-20261018/rollback/1Panel.app` 复制回 `/Applications/1Panel.app`，重新启动即可。保留原数据目录，不重置设置或执行迁移。详细校验清单、安装日志与截图保存在该验收归档中。

macOS 自动化可以操作页面，但不能触发原生窗口边缘缩放，已请求手动缩到最小尺寸以补齐原生窄窗检查。浏览器中的 900px 通过不视为原生证明。Windows/Linux 保留既有平台分支，没有声称完成其原生实测。
