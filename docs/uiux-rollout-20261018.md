- 15 个前端测试文件分别运行，131 项测试通过。另运行机柜布局、分组表格、SFTP 路径、工作区迁移和看板等既有脚本。

- 正式组件隔离验收使用仓库组件和独立 API 测试夹具，不连接真实主机、不写实际配置。覆盖 900/1050/1198/1688px，1/2/3/4/5/8/16 台分组；检验浮层与更多互斥、多选与 Shift 连选、键盘切换、活动工具可见、浅/深色、20px 字号和 400px 侧栏。

- 主题测试存在同进程 mock 污染，按测试文件隔离运行后均通过。构建仍有既有大 JS 分包提示；未为本次视觉调整扩展构建重构。

### macOS 原生最小窗口复测

正式 `/Applications/1Panel.app` 的窗口记录为 900×700。以下操作在原生窗口内完成，使用真实主机的只读数据；浏览器隔离页仅补充长内容的布局测量。

| 检查 | 原生结果 |
| --- | --- |
| 通栏收纳 | “更多”可打开；End/Enter 选中定时任务后，活动标签直接显示在通栏；菜单关闭后页面可继续操作。 |
| 主机浮层 | 与“更多”双向互斥；普通点击切换主机并关闭浮层；⌘B 开关、Escape 关闭及焦点返回正常。 |
| 主机选择 | ⌘多选、Shift 连选保留浮层；右键显示“已选 2 台”，未执行批量写入操作。 |
| 主机与文件状态 | 在 cdcp-raven 与 itjun-debian 间往返，主机标识、目录和当前工具对应正确；两台主机分别保留单栏/展开状态。进入的测试目录已回到原路径。 |
| 文件单双栏 | 默认远程单栏；展开现有本机对端后窄窗上下排列；筛选独立，目录双击、折叠及重新展开正常。 |
| 发现并修复 | 真实网卡明细表的长列会使概览整页横向溢出。提交 `2bf3116` 为概览表增加局部滚动容器，保留所有列；安装后确认整页不再横向滚动，表内可滚到末列。 |

修复后再次通过类型检查、构建和壳层检查。隔离长 IP 表测得表宽约 913px、表容器 785px，页面滚动宽度与可见宽度均为 817px。签名验证通过，安装后二进制与签名包 SHA-256 一致；更新后再次验证了通栏、主机切换和文件单双栏。

本次核对原数据目录 746 个文件，无文件丢失，仅正常界面会话记录 `app_sessions.json` 更新；其余数据、47 个 SSH 配置文件及三个原有未提交文件均与复测前校验一致。截图、校验结果与打包日志位于验收归档的 `native-narrow-retest/`。
