在 Mac 上安装 1Panel

将应用拖入“应用程序”，再按系统提示确认首次打开。这份指南也可以离线查看。

  • 芯片 Apple M 系列
  • 系统 macOS 13 Ventura 或更高

  1. 下载并打开 DMG

    在官方发布页的 Assets 中，下载名称以 mac-arm64.dmg 结尾的文件，双击打开。

    前往下载 macOS 安装包

    已经打开磁盘映像？直接继续下一步。Source code 是开发源码，安装时无需下载。

  2. 拖入“应用程序”

    把磁盘映像里的 1Panel.app 拖到旁边的 Applications（应用程序） 文件夹。等待复制完成。

    复制完成后，从 Finder 的“应用程序”打开 1Panel；磁盘映像可以推出。

  3. 尝试打开一次

    双击“应用程序”里的 1Panel。如果系统提示“无法验证开发者”或“Apple 无法检查是否包含恶意软件”，先点“完成”或“好”关闭提示，并保留应用。

    确认下载来源后再继续。 当前免费分发版本尚未经过 Apple 公证。请确认安装包来自 itjun/1Panel 官方发布页。

  4. 在系统设置中确认打开

    打开“系统设置”，进入“隐私与安全性”，向下找到“安全性”区域，确认提示中的应用是 1Panel，点“仍要打开”。按系统要求验证身份，再点“打开”。

    系统设置 › 隐私与安全性 › 仍要打开
    打开隐私与安全性

    浏览器可能先询问是否打开“系统设置”。按钮没有响应时，从屏幕左上角的苹果菜单手动进入。确认完成后，就能正常双击打开应用。

遇到问题

找不到“仍要打开”按钮

先从“应用程序”尝试打开一次 1Panel，再进入“隐私与安全性”。Apple 说明此按钮通常在尝试打开后约一小时内可用；超过时间可重新尝试打开应用。如果 Mac 由公司或学校管理，可能需要联系管理员。

提示“已损坏”或“会损害你的电脑”

这与“无法验证开发者”提示不同，请停止安装。从官方发布页重新下载；如果仍有问题，请在 GitHub Issues 提供安装包文件名、Mac 芯片、macOS 版本和完整提示，便于检查包的完整性。

需要执行终端命令或自行编译吗？

正常安装使用已打包的 DMG，按上面的系统操作确认即可，无需删除签名、运行终端命令或编译源码。重新下载其他版本时，macOS 可能要求再次确认。

Intel Mac 可以安装吗？

当前 macOS 安装包只支持 Apple 芯片（M 系列），并要求 macOS 13 或更高。可以在苹果菜单的“关于本机”中查看芯片和系统版本。

打开后没有远程主机

安装后可以先使用本机工作区。远程主机读取你自己电脑上的 SSH 配置；已有配置会自动加载，也可以在应用中添加主机。安装包不包含其他人的主机凭据。
