安装 1Panel

选择电脑对应的平台，下载已打包的应用。所有安装包均来自 GitHub 官方发布页，最新正式版。

macOSWindowsLinux

macOS

Apple 芯片 M 系列 · macOS 13 Ventura 或更高

下载 DMG
  1. 打开安装包。 下载名称以 mac-arm64.dmg 结尾的文件，双击打开。
  2. 拖入应用程序。 将 1Panel.app 拖到 Applications 文件夹，等待复制完成。
  3. 确认首次打开。 从“应用程序”双击 1Panel。若提示无法验证开发者，关闭提示后，进入“系统设置 → 隐私与安全性”，找到 1Panel 并点“仍要打开”，按提示确认。
  4. 正常启动。 完成确认后，可从“应用程序”打开 1Panel，并推出磁盘映像。

也可以使用终端命令

先将应用拖入“应用程序”并退出 1Panel，再按命令说明清理下载隔离属性；需要重置签名时，可覆盖为本地签名并校验后启动。

查看清理隔离属性与重置签名命令

当前免费分发版本尚未经过 Apple 公证。完整操作图解、命令和常见问题见 macOS 详细安装指南。Intel Mac 暂无对应安装包。

Windows

Windows 10 / 11 · x64

下载 ZIP
  1. 下载并解压。 下载名称以 win-amd64.zip 结尾的文件，右键选择“全部解压缩”，将文件放到你准备长期保留的目录。
  2. 运行应用。 在解压后的目录中双击 1Panel.exe。
  3. 处理首次提示。 如果 SmartScreen 显示“Windows 已保护你的电脑”，确认来自官方发布页后，点“更多信息 → 仍要运行”。受公司策略管理的电脑可能需要管理员处理。
  4. 开始使用。 打开本机工作区，或使用已有 SSH 配置连接远程主机。可为 1Panel.exe 创建桌面快捷方式。
提示缺少 WebView2 Runtime

从 微软 WebView2 官方下载页 安装 Evergreen Runtime（x64），完成后重新打开 1Panel。安装普通 Edge 浏览器不等同于安装 WebView2 Runtime。

远程主机或系统终端不可用

应用读取当前用户的 %USERPROFILE%\.ssh\config。打开系统终端时需安装 Windows OpenSSH 客户端，可在“设置 → 应用 → 可选功能”中添加。Windows Terminal 为可选终端，具体配置见 项目说明。

更新时先退出应用，再替换为新版本的 1Panel.exe；也可以使用应用内更新。

Linux

amd64 桌面环境 · Debian 13 已验证

下载 tar.gz
  1. 准备桌面运行环境。 当前桌面版使用 GTK 4 和 WebKitGTK 6.0。Debian 13 可在终端执行以下命令安装运行库。
sudo apt-get update &&
sudo apt-get install -y libgtk-4-1 libwebkitgtk-6.0-4
  1. 下载并解压。 下载名称以 linux-amd64.tar.gz 结尾的文件，在文件管理器中解压。进入其中包含 1Panel 可执行文件的目录。
  2. 启动应用。 在该目录中打开终端，执行：
chmod +x ./1Panel &&
./1Panel
可选：放到固定的用户目录

在解压目录执行以下命令，将主程序复制到用户目录，然后从固定位置启动。

install -Dm755 ./1Panel "$HOME/.local/bin/1Panel" &&
"$HOME/.local/bin/1Panel"

此步骤只安装主程序；原压缩包还附有桌面入口文件和图标，可按桌面环境需要配置。

提示缺少动态库，或没有可用显示器

请在已登录的桌面环境中运行。其他发行版需要提供匹配的 GTK 4、WebKitGTK 6.0 及兼容的系统运行库。若提示 GLIBC_… not found，请使用兼容的发行版版本；不要直接替换系统 glibc。反馈问题时请附发行版、架构和完整终端输出。

依赖信息可参考 Debian 官方 WebKitGTK 运行库说明。当前 Release 提供 tar.gz，仓库中的 deb / rpm / AppImage 任务属于开发构建入口。

装好后，先打开本机工作区

查看当前电脑无需配置远程主机。已有 SSH 配置会自动加载，也可在应用中添加主机。下载的是完整安装包，正常安装无需拉取代码或自行编译。
