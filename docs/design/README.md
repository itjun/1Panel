## 通知中心本地验收

2026 年 10 月 19 日的验收记录为通过：主机系统采用“消息记录 / 主机订阅 / 告警规则”，应用服务采用“消息记录 / 应用订阅 / 告警规则”；证书提醒与共享发送渠道保留独立入口。订阅与规则使用独立页面。

详细记录、原型对照和截图保留在本地 `notification-center/` 目录，由 Git 忽略。该轮覆盖 macOS 原生、窄窗、暗色隔离、通知分类及证书测试；Windows/Linux 实机与企业微信真实发送未在该轮执行。
