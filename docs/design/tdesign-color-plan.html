迁移顺序与验收

  1. 先对齐主题源。 固定官方版本，维护浅色和深色的完整语义表；同步生成 globals.css 默认值、启动骨架、看板回退和安装页面所需子集。同步更新视觉规范 §2、§4.7、§8、§9 及监控曲线规范。
  2. 再迁移壳层和基础控件。 从按钮、输入、Tag、表格行、导航、选区、焦点和禁用态开始。清理会二次改写品牌色的动态调色分支；将实际需要加深的文字登记为独立角色。
  3. 再迁移业务。 先校验主机监控、测速和看板，再覆盖文件、配置、应用、通知和日志。ECharts 主题切换时立即重建；用固定样本验证 B→A 与流入同色、A→B 与写入同色，整段贴合时能分别读值。
  4. 最后校验所有宿主。 浅色、深色、跟随系统、冷启动、外观切换、增强对比、降低透明度；macOS / Windows / Linux 的原生窗口分别验证，HTTP 看板独立打开，官网与离线页断网打开。
