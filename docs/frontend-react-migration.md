# 前端 React 迁移

Wails 主入口已经是 React。默认窗口、`?mode=terminal`、`?mode=board` 都挂 React。Vue 与 Element Plus 的活跃构建已从 `frontend/src` 移除。

迁移前的未提交界面改动已备份为 git stash：`迁移前工作区备份：设计令牌与界面改动`。工作区本身没有被收走，后续改动继续叠在这份 diff 上。

## 已确认

- 表行高 48px，表头 40px。虚拟表常量与 CSS 变量使用同一数值。
- 配置中心五个分段整页属于组 1。组 3 只迁主机侧文件、Nginx、apt、Hosts，并复用组 1 的代码区。
- 旧模块全部复活，并用 React 重写，不把 Vue 文件留作这些页面的最终实现。
  - 旧全局概览与现在的主机首页并存，归组 1，单独入口，不替换首页。
  - 旧主机概览归组 2。主机功能栏仍只有一个「概览」：`HostInfoView` 的 SSH / Agent 信息，和 `OverviewView` 的卡片与指标都留在这一页。
  - 本机八页和巡检归组 4，重新挂上入口。

## 设计基调

| 用途 | 值 |
|---|---|
| 画布 | `#F3F4F6` |
| 内容面 | `#FFFFFF` |
| 主文字 | `#20252B` |
| 次文字 | `#687382` |
| 分隔线 | `#DFE3E8` |
| 品牌蓝 | `#005EEB`，只用于主要操作、选中、焦点 |
| 表行 / 表头 | 48px / 40px |
| 圆角 | 控件 4px，卡片和浮层 8px，表格 0 |
| 左轨 | 画布底；选中为淡蓝底加品牌蓝字，无描边 |
| 主机首页 | 白色分组面板，分组色只做浅底 |
| 看板 | 石墨深底 |
| 终端 / 代码 / 日志 | 石墨表面，保留 ANSI |

界面字体和字号继续读 `ipannel.settings.v1`。卡片细边框、默认无阴影。浮层用克制阴影。Tailwind 预检样式不得改变 `.xterm` 和 CodeMirror。

技术栈：React、TypeScript、Vite、shadcn/ui 源码组件、Tailwind、TanStack Table、TanStack Query。保留现有 Wails 绑定、ECharts、xterm、CodeMirror。不改公开 API、后端数据结构或业务流程。

全部确认后把主入口切到 React，回归后移除 Vue / Element Plus 活跃构建和 `?mode=react`。看板窗 `?mode=board`、终端窗一起切。然后删除本迁移规则。
